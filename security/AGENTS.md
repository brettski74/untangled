# Security review evidence — not architectural intent

Contents under this directory are **auditable review evidence and candidate findings**.

They are **not** governing architecture, product requirements, or accepted security policy.

Durable security intent lives only in committed, `Accepted` files under `/architecture/security/` (threat model and security requirements). Primary workflows (refine, implement, diagnose, verify, and similar) must not treat review reports, manifests, or `findings.md` here as requirements or design authority.

Security skills may read this tree as evidence when explicitly invoked. Other agents should ignore it unless a human or security skill supplies it as review material.
